## Version Control

Commit and push to GitHub regularly throughout all work sessions. Every meaningful unit of progress (new feature, bug fix, refactor, etc.) should be its own commit with a clear, descriptive message. Never let significant work accumulate uncommitted. This ensures no work is ever lost and the repo always reflects current status.
